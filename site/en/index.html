Principles

Four rules decide every trade-off

Office software either locks your files in the cloud, makes you sign up, or fills the sidebar with upsells. YiiOffice does the opposite: double-click and the file opens, and nothing is missing when the network is.

01

Local-first

Opening, editing, saving and converting all happen on your machine. No accounts, no mandatory sync, and no background update checks.

02

Actually editable

Not a viewer: all five editors open, edit and save the native format, and MS Office or WPS opens the result as usual.

03

Clean

No login walls, no ads, no telemetry, no hidden paid tiers. The only default network access is loading remote images a document references.

04

Format-first

Reads and writes .docx / .xlsx / .pptx / .pdf directly — no private format, no import step.

Editors

Five editors, one shell

Every editor runs embedded as a tab or standalone for debugging. Switching tabs only shows and hides a view — scroll position, caret and undo stack survive.

Docs

Tiptap 3 + docx-engine .docx
  • Paged and multi-page views, ruler and page setup
  • Headers, footers, page numbers and sections
  • Style gallery, footnotes, comments, document compare
  • Fields and formulas, ink, find and replace, word count
  • Document protection and encrypted files
  • Print and PDF export

Univer 1.2 + Rust sidecar .xlsx .xlsm .csv

  • Merge and freeze, go-to, single-variable solve
  • Series fill, paste special, name manager
  • Sheet protection and paged printing

Slides

Capabilities

The hard parts sit below the editors

Saves that keep formatting, crashes that never leave half a file, search that finds Chinese words — the parts you only notice when they break.

Byte-faithful saves

Only the XML nodes you edited are rewritten, so styles, comments, embedded objects and macros survive a round trip.

Atomic writes

Every save goes through a temporary file and a rename, so a crash or a power cut cannot leave a half-written document.

Local full-text search

Built on node:sqlite FTS5 across names, paths and body text. CJK content gets bigram and unigram token streams, so two-character queries hit long strings.

Headless export

--headless-export converts to PDF without opening a window, and --json prints one structured line for scripts.

Multi-tab host

Each tab is its own WebContentsView; switching only shows and hides it, so scroll position, caret and undo stack stay where you left them.

Two languages

All UI copy lives in @yiioffice/i18n as Chinese and English, kept apart from feature code.

No update checks and no telemetry. The only default network access is loading remote images a document references. The font download in Slides stays off unless a font CDN URL was baked in at build time.

Quick start

Build it from source

You need Node.js 22.12 or newer and npm 10 or newer. cargo is only required to compile the Rust sidecar behind Sheets.

Node.js
≥ 22.12
npm
≥ 10
Rust
stable (optional)
OS
Windows 10 / 11
npm install downloads the Electron binary in its postinstall step; a mirror variable works if that is slow. 
# install every workspace at once
npm install

# generate the .docx test fixtures
npm run fixtures

# five renderer dev servers :5173-:5177 plus the Electron main process
npm run dev
# portable zip
npm run dist:win

# NSIS installer (installs to D:\YiiOffice by default)
npm run dist:win:installer

# just build and launch
npm run shell
# all 19 workspace test projects
npm test
npm run typecheck
npm run lint

# colors must come from theme variables; comments must be English
npm run check:theme-colors
npm run check:english-comments
Debug one editor on its own with npm run dev:docs, dev:sheets and friends — it opens its own window and skips the shell.

FAQ

The questions people ask first

Does it need a network connection or an account?
Neither. There is no account system and nothing is uploaded; editing, saving, search and format conversion all run locally. The app never checks for updates and never reports usage.
Will MS Office or WPS open a file after YiiOffice saves it?
Yes. Saving rewrites the OOXML package as a patch: only edited nodes change and every other byte is copied through, so the structures Office understands stay intact.
Which platforms and installers exist?
Windows 10 and 11 (x64 and arm64). npm run dist:win produces a portable zip, npm run dist:win:installer an NSIS installer that installs per user without a UAC prompt and keeps a machine-wide option. There is no auto-update channel.
Does search find Chinese text?
Yes. FTS5's unicode61 tokenizer does not split runs of Chinese, so the index also stores bigram and unigram streams; two-character and single-character queries both hit.
npm run dev runs, but the editor tab is blank?
Check that all five renderer dev servers (:5173-:5177) are alive. Each editor tab loads its own server, so a taken port or a crashed renderer shows up as a white tab.
Is there CI?
Not yet. Lint, typecheck and tests all run locally. There are known historical failures in the suite, so run the affected workspace before you change it.
