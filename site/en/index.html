Editors

Your files. Your call.

Open, edit and save on your own disk. The app never uploads, syncs or backs anything up for you — where a file lives and what it is called stays your decision.

Where the network ends
01

Works with the network off

Editing, saving, search and conversion all run locally. There is exactly one default outbound request: loading remote images a document points at. The font download for slides only turns on when a CDN address is injected at build time.

02

Saving costs no formatting

Saves are OOXML patches: only the nodes you touched are rewritten, every other byte stays as it was. Styles, comments, embedded objects and macros survive, and Word or WPS opens the result as usual.

03

No account, no ads

No sign-up, no usage data, no update pings. There is no hidden paywall in the interface — the main screen is just your own file list.

Capabilities

The hard parts, handled outside the editors.

Saves that never corrupt a file, crashes that never lose work, search that finds Chinese text — the quiet parts are what you rely on daily.

Atomic writes

Every save goes through a temporary file and a rename, so a crash or a power cut never leaves half a file behind.

Local full-text search

FTS5 on node:sqlite, covering names, paths and body text. Chinese is indexed as both bigrams and unigrams, so two-character queries match long strings.

A multi-tab host

Each tab is its own WebContentsView. Switching only shows and hides it, so the editor keeps its full state.

Headless export

--headless-export converts to PDF without opening a window, and --json prints one structured line for scripts and batch jobs.

Two languages

Interface strings live in @yiioffice/i18n, switchable between Chinese and English, decoupled from feature code.

Print and export

All five editors print directly; Docs and Markdown export to PDF, Slides exports to SVG and images.

FAQ

A few things you may want to know.

Do I need a network connection or an account?
Neither. There is no account system and nothing is uploaded; editing, saving, search and conversion all happen locally. The app does not check for updates and does not collect usage data.
Will Word and WPS open what I save?
Yes. Saves are OOXML patches: only the edited nodes change, every other byte stays as it was, so the structure Office expects is untouched.
Which platforms are supported?
There is a ready-made NSIS installer for Windows 10 / 11 (v0.13.0). macOS and Linux build from source today: npm run dist:mac or npm run dist:linux. There is no auto-updater — upgrading means downloading again.
Can search find Chinese text?
Yes. FTS5's unicode61 tokenizer does not split continuous Chinese, so the index also emits bigram and unigram tokens; both two-character and single-character queries match.
npm run dev runs, but editor tabs stay blank?
Check that all five renderer dev servers (:5173–:5177) are alive. Each editor tab loads its own dev server, so an occupied port or a crashed renderer gives you a blank tab.
Is there CI?
The code lives in two places: GitHub upstream and a Gitee mirror for China. There is no CI configuration yet — lint, type checks and tests run locally, and there are known pre-existing failures, so check the baseline in the relevant workspace before changing it.

Open source. Change anything.

The code, the component split and the build scripts are all in the repository — there is no hidden paid tier. Add an editor, restyle the interface, or make one format read more accurately: go ahead.
