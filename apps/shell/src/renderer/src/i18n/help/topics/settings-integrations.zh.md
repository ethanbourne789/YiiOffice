# 设置、语言、主题与集成

## 打开设置

主屏左下角的账号行打开设置面板（未登录时显示为「登录」）。面板共几个分区：账户、通用、集成、关于。

![设置 ▸ 通用：语言、主题、自动保存与使用统计开关都在这里](img/settings-general.png)

## 语言

- 设置里可选 **2 种界面语言**：简体中文、English。
- 切换立即生效并持久化；菜单栏（主进程菜单）随语言重建。

## 主题

浅色 / 深色 / 跟随系统三种。跟随系统时随 OS 外观自动切换，编辑器区域同步换肤，无闪白。

## 通用

- **发送匿名使用统计** —— 默认开启。使用 Google Analytics 4，会发送你的公网 IP 地址和传输元数据；文档内容和文件名绝不收集，每个事件只带一个类型，比如「打开了一个 .docx」。随时可以在这里关闭。
- **所有文档自动保存** 会让每个编辑器默认开启自动保存；单个窗口仍然可以关掉。
- **默认保存位置**配**更改**按钮，以及**设为 Office 文档默认程序**，把 .docx / .xlsx / .pptx 交给 YiiOffice 处理。

## 关于

- **版本**、项目的 GitHub 链接，以及**去 GitHub 点 Star**按钮。
- **更新通道**：稳定版或 Beta 版。改完立即生效并检查更新；它不会把 Beta 版安装退回稳定版。

## 默认应用绑定

设置里可以把 .docx / .xlsx / .pptx / .pdf 等格式关联为「由 YiiOffice 打开」（写入系统级别的默认应用注册，按平台提示确认）。

## 第三方声明与更新

- 帮助菜单 ▸ 第三方软件声明：随包附带的完整开源组件许可清单。
- 帮助菜单 ▸ 检查更新：手动触发一次更新检查；有新版本时提示安装。

## 账号登录

- 设置或云端项目列表里的登录入口走**设备码**流程：YiiOffice 显示验证码并在浏览器打开登录页，完成后自动继续。
- 登录只用于：云端项目列表、官方模型服务。不登录时本地功能与自定义模型完全可用。
- 登出在设置里一键完成。
